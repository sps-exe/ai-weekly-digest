## 🚀 Quick Start

### Option A — Web App (fastest)
1. Open `index.html` in Chrome/Firefox — no server needed
2. Enter your **Groq key** (`gsk_...`) — free at [console.groq.com](https://console.groq.com)
3. Optionally add a **Pexels key** for real photos — free at [pexels.com/api](https://www.pexels.com/api/)
4. Click **Save & Load** → the app fetches news, generates post, and finds images
5. **Copy the post** + **download an image** → paste both into LinkedIn

### Option B — Chrome Extension
1. Open `chrome://extensions` in Chrome
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked** → select the `extension/` folder
4. The 🧠 icon appears in your toolbar
5. Click it → enter keys → get your post in the popup
6. On LinkedIn, click **⚡ Fill LinkedIn Draft** → the composer fills automatically

## 🆓 Free API Keys

| Service | Key format | Get it |
|---|---|---|
| **Groq** (required) | `gsk_...` | [console.groq.com](https://console.groq.com) — no credit card |
| **Pexels** (optional) | any string | [pexels.com/api](https://www.pexels.com/api/) — free signup |

Without a Pexels key, images are AI-generated by [Pollinations.ai](https://pollinations.ai) — no key needed at all.

---

## 🔒 Privacy

- API keys stored only in your browser (`localStorage` / `chrome.storage.local`)
- Keys sent **only** to the respective APIs (Groq, Pexels)
- No analytics, no tracking, no external server

## 🛠 Rebuild Extension Files

If you want to modify the extension and regenerate icons:


Requires Python 3.6+ (stdlib only — no pip installs).

## ⚠️ LinkedIn Note

The Chrome extension **fills** your post draft but **never auto-posts**. You always click Post yourself. This is the same pattern used by Grammarly and other LinkedIn-approved tools, keeping your account safe.
